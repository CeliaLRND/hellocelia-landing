Page statique pour la bio. Aucune étape de build.

1. Dans `index.html`, remplacer `href="#"` et `XX` par le lien et le prix du guide.
2. Pousser sur GitHub, puis Settings > Pages > Deploy from a branch > `main` / racine.
3. Les sections « Les articles » et « Ce que j'utilise » ont des lignes de placeholders à remplacer dans `index.html`.
