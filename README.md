# hellocelia

Page statique pour la bio, servie par GitHub Pages. Aucune étape de build.

- Contenu : tout est dans `index.html`, le style dans `style.css`.
- Section articles : masquée pour l'instant (attribut `hidden` dans `index.html`).
- Mise en ligne : chaque push sur `main` republie le site (Settings > Pages > Deploy from a branch > `main` / racine).
